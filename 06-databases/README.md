# 🗄️ Azure Databases

> **AWS Parallel:** RDS / Aurora / DynamoDB → Azure SQL / Cosmos DB  
> **GCP Parallel:** Cloud SQL / Spanner / Firestore → Azure SQL / Cosmos DB

## Database Services Overview

| Azure Service | AWS Equivalent | GCP Equivalent | Use Case |
|---|---|---|---|
| **Azure SQL Database** | RDS SQL Server / Aurora | Cloud SQL (SQL Server) | Managed SQL Server PaaS |
| **Azure SQL Managed Instance** | RDS SQL Server | Cloud SQL | Full SQL Server compatibility |
| **Azure Database for PostgreSQL** | RDS PostgreSQL / Aurora PG | Cloud SQL PostgreSQL | Managed PostgreSQL |
| **Azure Database for MySQL** | RDS MySQL / Aurora MySQL | Cloud SQL MySQL | Managed MySQL |
| **Azure Database for MariaDB** | RDS MariaDB | — | Managed MariaDB |
| **Azure Cosmos DB** | DynamoDB + DocumentDB | Firestore + Spanner | Multi-model globally distributed |
| **Azure Cache for Redis** | ElastiCache Redis | Memorystore Redis | In-memory caching |
| **Azure Synapse Analytics** | Redshift + Glue | BigQuery | Data warehousing |
