# 🔒 Azure Security

> **AWS Parallel:** GuardDuty + Security Hub + KMS → Microsoft Defender + Sentinel + Key Vault  
> **GCP Parallel:** Security Command Center + Cloud KMS → Defender + Key Vault

## Security Services Overview

| Azure Service | AWS Equivalent | GCP Equivalent | Purpose |
|---|---|---|---|
| **Microsoft Defender for Cloud** | Security Hub + GuardDuty | Security Command Center | Unified security posture |
| **Microsoft Sentinel** | AWS Security Lake + Detective | Chronicle SIEM | Cloud-native SIEM/SOAR |
| **Azure Key Vault** | AWS KMS + Secrets Manager | Cloud KMS + Secret Manager | Key and secret management |
| **Azure DDoS Protection** | AWS Shield | Cloud Armor | DDoS mitigation |
| **Azure WAF** | AWS WAF | Cloud Armor | Web application firewall |
| **Microsoft Entra PIM** | AWS IAM Access Analyzer | IAM Recommender | Privileged access management |
| **Azure Firewall** | AWS Network Firewall | Cloud Firewall | Stateful L7 firewall |
