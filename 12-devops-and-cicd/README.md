# 🚀 Azure DevOps & CI/CD

> **AWS Parallel:** CodePipeline + CodeBuild + CodeDeploy → Azure DevOps Pipelines  
> **GCP Parallel:** Cloud Build + Cloud Deploy → Azure DevOps Pipelines / GitHub Actions

## DevOps Services Overview

| Azure Service | AWS Equivalent | GCP Equivalent | Purpose |
|---|---|---|---|
| **Azure DevOps** | CodePipeline + CodeBuild | Cloud Build | Full DevOps platform |
| **Azure Repos** | CodeCommit | Cloud Source Repositories | Git repository |
| **Azure Pipelines** | CodePipeline + CodeBuild | Cloud Build | CI/CD pipelines |
| **Azure Artifacts** | CodeArtifact | Artifact Registry | Package management |
| **Azure Boards** | Jira (AWS partner) | Jira (GCP partner) | Work item tracking |
| **GitHub Actions** | GitHub Actions | GitHub Actions | CI/CD via GitHub |
