# 📊 Monitoring and Governance

> **AWS Parallel:** CloudWatch + AWS Config + CloudTrail → Azure Monitor + Azure Policy + Activity Log  
> **GCP Parallel:** Cloud Monitoring + Cloud Audit Logs + Security Command Center → Azure Monitor + Azure Policy + Defender

## Monitoring Services Overview

| Azure Service | AWS Equivalent | GCP Equivalent | Purpose |
|---|---|---|---|
| **Azure Monitor** | CloudWatch | Cloud Monitoring | Metrics, logs, alerts |
| **Log Analytics** | CloudWatch Logs Insights | Cloud Logging | Log query and analysis |
| **Application Insights** | X-Ray + CloudWatch | Cloud Trace | APM, distributed tracing |
| **Azure Policy** | AWS Config Rules | Organization Policy | Compliance enforcement |
| **Activity Log** | CloudTrail | Cloud Audit Logs | API call history |
| **Advisor** | Trusted Advisor | Recommender | Best practice recommendations |
| **Service Health** | AWS Health | Google Cloud Status | Azure service incidents |
| **Workbooks** | CloudWatch Dashboards | Cloud Monitoring dashboards | Custom dashboards |
